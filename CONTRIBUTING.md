# Contributing

Thanks for helping make search simple!

## Reporting a bug

1. Check the [issues](../../issues) page to see if it's already reported.
2. Open a new issue with a clear title, the search you used, your browser, and a screenshot if you can.

## Sending a fix

1. Fork the repo and make your change.
2. Test it by loading the folder as an unpacked extension (see the [README](README.MD)).
3. Open a pull request describing what you changed and why.

The code is small: `content.js` (hiding logic), `blocker.css` (instant hiding), `manifest.json` (settings).
